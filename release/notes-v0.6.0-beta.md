# PXLNET Connect 0.6.0-beta

Большое обновление управления подключением и персонализации.

- Новый виджет PXLNET для главного экрана Android: состояние VPN, сервер, срок подписки и включение одним нажатием. На Android 12+ он подстраивается под цвета Material You.
- Уведомления об окончании подписки за 7, 3 и 1 день, а также после окончания, с кнопкой продления через @pxlnet_bot.
- Готовые режимы маршрутизации: «Всё через VPN», Smart Routing, «Игры», «Видео», «Банки» и ручной выбор приложений.
- Для готовых профилей приложение находит установленные поддерживаемые приложения; список можно скопировать и отредактировать вручную.
- Пикс стал полноценным живым маскотом рядом с кнопкой подключения: меняет состояние, анимируется и показывает короткие подсказки. Анимации и подсказки отключаются отдельно.
- Карточка PXLNET на главной теперь компактно объединяет профиль, имя Telegram-аккаунта и срок подписки без дублирующего блока.
- Срок подписки из Telegram-аккаунта используется виджетом и напоминаниями; гостевой режим по ссылке продолжает работать.
- Добавлены английские тексты для новых экранов и русский перевод; для остальных языков используется английский вариант.

Версия 0.6 не меняет серверную архитектуру, формат подписки и работу 3x-ui.
