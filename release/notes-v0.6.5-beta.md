# PXLNET Connect 0.6.5-beta

Новый главный экран: подключение и его реальное состояние на первом плане, выбранный сервер — сразу под ним. Выбор серверов теперь называется «Выбор сервера»; страны показаны векторными флагами, а протокол и задержка — отдельно от названия.

- Тема следует системе либо переключается вручную; в настройках есть отдельный переключатель цветов обоев (Monet) и наглядный выбор одного из шести акцентов.
- Короткая анимация при запуске и появлении главной кнопки; компактная строка подписки наверху показывает имя и срок действия.
- Первоначальная настройка стала понятнее и запускается повторно из настроек приложения. Сохранённая подписка доступна для подключения без входа через Telegram.
- Основная кнопка, виджет и плитка быстрых настроек используют общий запуск VPN.
- Обновлено VPN-ядро sing-box и исправлена адаптивная иконка приложения.
- Подписка, содержащая XHTTP VLESS и совместимые Hysteria2-серверы, теперь импортирует совместимые серверы; XHTTP-only подписка показывает явную ошибку.

**Ограничение:** XHTTP VLESS в этой версии не работает — выбранное ядро не поддерживает этот транспорт. Подключение к таким узлам не заявлено исправленным; поддержка XHTTP будет отдельной задачей. Работа VPN на конкретном телефоне требует пользовательского теста.

Для обновления поверх прежних бета-версий используется тот же ключ подписи. Файлы: arm64-v8a APK для современных смартфонов, universal APK для всех поддерживаемых ABI, метаданные автообновления и SHA256SUMS.txt.
