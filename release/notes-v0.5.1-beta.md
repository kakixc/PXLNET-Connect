# PXLNET Connect 0.5.1-beta

Исправление встроенного обновления на Android и MagicOS.

- Добавлен системный запрос разрешения на установку обновлений из PXLNET Connect.
- После скачивания APK открывается штатный установщик Android через защищённый FileProvider URI.
- Диалог обновления остаётся доступным после возврата из настройки разрешения.
- Уже скачанный APK используется повторно без новой загрузки.
- Обычный Package Installer больше не определяется как «тихая установка»; такой режим оставлен только Root/Shizuku.

Первый переход с 0.5.0 на 0.5.1 нужно выполнить вручную, потому что исправление установщика ещё отсутствует в установленной версии 0.5.0.
