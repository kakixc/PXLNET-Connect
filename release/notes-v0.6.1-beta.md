# PXLNET Connect 0.6.1-beta

Срочное исправление версии 0.6.0.

- Планирование напоминаний перенесено из критического пути запуска приложения в безопасную фоновую инициализацию.
- Ошибка Android при создании уведомления без выданного разрешения больше не может завершить процесс приложения.
- Маскот Пикс заметно уменьшен и больше не занимает половину главного экрана.
- Сохранены виджет, готовые профили маршрутизации, напоминания 7/3/1 и компактная карточка аккаунта из 0.6.0.

Серверная часть и формат подписки не изменены.
