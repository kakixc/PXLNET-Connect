# PXLNET Connect 0.4 Beta

Первый публичный beta-релиз Android-клиента PXLNET.

## Основное

- VPN на базе sing-box с VLESS и Hysteria2;
- гостевой режим по ссылке подписки;
- вход через `@pxlnet_bot` и безопасное хранение токена в Android Keystore;
- отображение и синхронизация статуса подписки;
- отдельный раздел аккаунта: вход, покупка, продление и ручное добавление существующей подписки;
- PXL Guard с автоматическим переключением на доступный сервер;
- Smart Routing и полный туннель;
- экран состояния узлов и задержки;
- плитка быстрых настроек Android;
- инструкция Always-on VPN;
- обезличенная отправка диагностики;
- автоматический поиск типовых ошибок и отчёт для поддержки;
- простой режим с двумя основными вкладками и отдельный режим разработчика;
- обновления через GitHub Releases.
- сокращённый набор Android-разрешений без геолокации и просмотра всех приложений;
- удалены унаследованные Xposed/VPN-hide компоненты: приложение не скрывает VPN от сервисов.

PXLNET Connect основан на `sing-box for Android`; интерфейс и часть продуктовых идей вдохновлены Happ Android. Проект выпускается по GPLv3. Новости: [@pxlnet](https://t.me/pxlnet), поддержка: [@pxlnet_bot](https://t.me/pxlnet_bot).

## Установка

Для большинства современных телефонов выбирайте APK `arm64-v8a`. Universal APK нужен только если архитектура устройства неизвестна.

Это beta-версия. Перед обновлением сохраните ссылку подписки.
