# Security policy

## Reporting a vulnerability

If **Report a vulnerability** is available on the [GitHub advisories page](https://github.com/kakixc/PXLNET-Connect/security/advisories), use it to send a private report. Otherwise, contact the maintainers via [PXLNET support](https://t.me/pxlnet_bot) and ask for a private security contact before sharing details.

Include the affected app version, the impact and a redacted description of the conditions under which it occurs. Use placeholder data. Keep vulnerability details, subscription URLs, access tokens, session data and personal information out of public issues, comments and attachments.

## Сообщение об уязвимости

Если на [странице безопасности GitHub](https://github.com/kakixc/PXLNET-Connect/security/advisories) доступна кнопка **Report a vulnerability**, отправьте приватный отчёт через неё. Иначе запросите закрытый контакт для отчёта у [поддержки PXLNET](https://t.me/pxlnet_bot) и дождитесь ответа, прежде чем передавать детали.

Укажите версию приложения, возможные последствия и условия возникновения проблемы. Используйте обезличенные данные. Не публикуйте детали в открытых Issues, комментариях или вложениях.
