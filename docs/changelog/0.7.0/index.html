PXLNET Connect 0.7.0

Стабильное обновление после 0.6.9-beta. Появились вход по почте, новые варианты главного экрана, Expressive DNS и поддержка VLESS XHTTP.

27 ноября 2026 · Android 7.0 и новее

Вход и подписки

  • Войти можно по одноразовому коду из письма или через Telegram. Connect загружает привязанные к PXL ID подписки, а гостям доступен импорт по ссылке.
  • При выходе очищаются профили, привязанные к аккаунту. Добавленные вручную профили сохраняются.
  • В настройках можно задать общий интервал обновления подписок и отключить автообновление для отдельных профилей.

Интерфейс

Доступны «Классика», «Фокус» и «Пульт». В «Пульте» кнопка VPN закреплена внизу, а профиль и сервер можно выбрать на главном экране. При обновлении сохраняется прежняя тема, на новой установке открывается «Пульт». Переходы и смена профиля стали плавнее.

VPN и Expressive DNS

  • Добавлена поддержка подключения по VLESS XHTTP через Xray. Доработаны проверка серверов, Smart Routing и восстановление связи через PXL Guard.
  • В Expressive DNS можно выбрать, какой DNS-сервис находит адреса сайтов, проверить его доступность и задать правила для доменов или приложений. Режим работает отдельно или вместе с VPN.
