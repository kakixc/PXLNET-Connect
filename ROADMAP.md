# Дорожная карта проектов PXL

## 1. PXLNET Connect

### Alpha 0.1 — сейчас

- Android 11–16, arm64;
- подключение по URL подписки;
- VLESS Reality и Hysteria2;
- Германия и Финляндия с флагами;
- AUTO/ручной выбор, задержка, скорость, трафик, срок подписки;
- без Telegram-аккаунта и без изменения серверной части.

### Alpha 0.2

- тест на Honor 400 и исправления MagicOS;
- экран первого запуска в три шага;
- QR-код подписки и безопасная вставка из буфера;
- красивый отдельный экран серверов до подключения;
- уведомления об окончании подписки;
- собственная release-подпись и безопасное обновление только сборок PXLNET.

### Beta

- Windows-клиент `.exe` с тем же UX;
- опциональная авторизация через Telegram;
- управление устройствами и отзыв доступа;
- PXLNET API вместо зависимости от формата панели.

## 2. HEX LAB Control — следующий проект

Панель управления 3D-печатью для HEX LAB:

- заказы, клиенты, статусы, сроки и расчёт себестоимости;
- синхронизация с Google Sheets или OneDrive/Excel;
- остатки катушек и списание материала через Spoolman;
- статусы принтеров, питание и уведомления через Home Assistant;
- файлы моделей, фотографии, чек-листы и история печати;
- мобильный адаптивный интерфейс на домашнем сервере.

Для первой версии HEX LAB Control таблица остаётся экспортом/резервной копией, а основным источником данных становится база приложения. Так меньше риск сломать формулы и проще подключить Spoolman и Home Assistant.
