# Contributing to PXLNET Connect

Reports and pull requests are welcome in English or Russian.

- Search [open and closed issues](https://github.com/kakixc/PXLNET-Connect/issues?q=is%3Aissue) before opening a report. Use the [issue chooser](https://github.com/kakixc/PXLNET-Connect/issues/new/choose) for bugs and feature ideas.
- For a bug, include the Connect version, Android version and steps to reproduce. Use a demo profile or remove subscription links, credentials, account details and private server addresses from any examples.
- For a code contribution, fork the project, branch from the current public `main` and open a pull request for one change at a time. Describe how you verified it. For interface changes, include a screenshot with demo data.
- Use the [build guide](BUILDING.md) to run the relevant tests and produce a debug APK. Keep signing files, local configurations and generated APKs or AARs out of the pull request.
- Follow the [security policy](SECURITY.md) for vulnerabilities.
